# 🖐️ Gesture Mouse Control

基于 **MediaPipe** 和 **OpenCV** 的手势识别鼠标控制系统。通过摄像头捕捉手势，实现鼠标移动和点击操作，无需物理鼠标。

## ✨ 功能特性

- **手掌追踪模式**：五指张开 → 掌心移动控制鼠标指针
- **锁定模式**：握拳 → 锁定鼠标，防止误触
- **手势左键单击**（锁定模式下）：比数字 **1**（仅伸食指）
- **手势右键单击**（锁定模式下）：比数字 **2**（伸食指 + 中指）
- **平滑追踪**：指数移动平均算法，减少指针抖动
- **连续帧稳定确认**：避免手势误识别

## 🧠 手势说明

| 手势 | 动作 | 模式 | 效果 |
|------|------|------|------|
| ✋ 五指张开 | 手掌展开 | 追踪模式 | 掌心移动 → 鼠标跟随移动 |
| ✊ 握拳 | 五指弯曲 | 切换 | 从追踪 → 进入锁定模式 |
| ☝️ 数字 1 | 仅伸食指 | 锁定模式 | **左键单击** |
| ✌️ 数字 2 | 伸食指+中指 | 锁定模式 | **右键单击** |
| ✋ 五指张开 | 手掌展开 | 锁定模式 | 切回追踪模式 |

## 🚀 快速开始

### 安装依赖

```bash
pip install opencv-python mediapipe pyautogui numpy
```

### 运行程序

```bash
python test.py
```

### 运行选项

编辑 `test.py` 顶部的配置常量：

```python
CAMERA_INDEX = 0          # 摄像头编号
HEADLESS_MODE = False     # 无窗口模式（True=后台运行）
```

## ⚙️ 可调参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `TRACKING_SMOOTHING` | 0.6 | 鼠标平滑度（0~1，越大越平滑） |
| `CLICK_COOLDOWN` | 1.0 秒 | 点击冷却时间，防止连击 |
| `STABLE_FRAME_COUNT` | 5 帧 | 手势稳定确认帧数 |

## 📋 环境要求

- Python 3.10 + OpenCV + MediaPipe + PyAutoGUI 
- 摄像头

## 🛠️ 技术栈

- **OpenCV** — 图像采集与显示
- **MediaPipe Hands** — 手部关键点检测（21个关键点）
- **PyAutoGUI** — 鼠标控制
- **NumPy** — 坐标映射计算
